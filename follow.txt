| Layer      | Function / Handler                  | Purpose                     |
| ---------- | ----------------------------------- | --------------------------- |
| Database   | `ConnectDB()`                       | Connect to MongoDB          |
| Database   | `GetCollection(name)`               | Get collection              |
| Database   | `CreateUserIndexes()`               | Unique index for email      |
| Repository | `CreateUser(user User) error`       | Insert user                 |
| Repository | `FindUserByEmail(email string)`     | Fetch user by email         |
| Service    | `RegisterUser(name,email,password)` | Hash + validate + save user |
| Controller | `Signup(c *gin.Context)`            | Handle signup request       |
| Controller | `Login(c *gin.Context)`             | Handle login request        |
| Controller | `GetProfile(c *gin.Context)`        | Fetch user profile          |

1️⃣ Database Layer (internal/database)
Function	Purpose
ConnectDB()	Connect to MongoDB and set the global client
GetCollection(name string) *mongo.Collection	Return a collection handle
CreateUserIndexes()	Create unique index on email field
DisconnectDB()	Optional: close MongoDB connection
2️⃣ Model Layer (internal/model)

You usually don’t need functions here — just structs.

Structs:

Struct	Purpose
User	Represents a user in MongoDB (ID, Name, Email, Password, CreatedAt, UpdatedAt)
3️⃣ Repository Layer (internal/repository)
Function	Purpose
CreateUser(user model.User) error	Insert a new user into MongoDB
FindUserByEmail(email string) (model.User, error)	Retrieve a user by email
UpdateUser(user model.User) error	Update existing user details
DeleteUser(id primitive.ObjectID) error	Optional: delete a user
ListUsers() ([]model.User, error)	Optional: list all users

Think of CreateUser() as your saveDb function.

4️⃣ Service Layer (internal/service) – optional but recommended
Function	Purpose
RegisterUser(name, email, password string) error	Business logic for signup (hash password, validate email uniqueness)
LoginUser(email, password string) (model.User, error)	Validate credentials and return user
UpdateUserProfile(user model.User) error	Business logic for updating profile
GetUserByID(id primitive.ObjectID) (model.User, error)	Fetch user details
ChangePassword(userID, oldPassword, newPassword string) error	Optional: secure password change
5️⃣ Controller Layer (internal/controller)
Function	Route	Purpose
Signup(c *gin.Context)	POST /signup	Accept signup request, call service, handle errors
Login(c *gin.Context)	POST /login	Accept login request, generate JWT token
GetProfile(c *gin.Context)	GET /profile	Return authenticated user profile
UpdateProfile(c *gin.Context)	PUT /profile	Update user profile
ChangePassword(c *gin.Context)	PUT /change-password	Change password securely
6️⃣ Utility / Helper Functions
Function	Purpose
HashPassword(password string) (string, error)	Hash password with bcrypt
CheckPasswordHash(password, hash string) bool	Compare plaintext password with hash
GenerateJWT(user model.User) (string, error)	Create JWT token for authenticated user
ValidateJWT(token string) (userID string, error)	Validate JWT and extract user info
